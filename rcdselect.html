RCD Types (AS/NZS 3000:2018 cl. 2.6.2.2.1 Notes; AS/NZS 3190, 61008.1, 61009.1, IEC 62423):
Type AC: Tripping ensured for residual sinusoidal AC. The general type used in Australia (not used in New Zealand).
Type A: As Type AC, plus residual pulsating DC.
Type I: As Type A, rated residual current ≤ 10 mA with interrupting time ≤ 40 ms — for patient areas (AS/NZS 3003).
Type F: As Type A, plus composite / high-frequency residual currents (frequency converters, electronic ballasts).
Type B: As Type A, plus AC up to 1 kHz and smooth DC residual currents (e.g. from rectifying circuits).
Type S: Time-delayed, for selectivity with downstream RCDs.
The waveform of possible earth-fault currents should be considered when selecting the type — consult the RCD manufacturer.
IΔn ratings: 10 mA (medical), 30 mA (personal protection), 100/300 mA (fire protection), 500 mA (equipment protection).
