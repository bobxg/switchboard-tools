Conduit Sizer (AS/NZS 3000)

Enter cable quantities to size a conduit run, or split the set across multiple conduits when a smaller maximum size is preferred.
Fill factors per AS/NZS 3000:2018 Appendix C Table C2: 1 cable = 53%, 2 cables = 31%, 3+ cables = 40%.

Layouts are packed largest-to-smallest, then each run is resized to the smallest conduit that still complies with the applicable fill factor.
